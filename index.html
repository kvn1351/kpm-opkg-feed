Kindle KPM Homebrew Feed for OPKG

Automated bridge compiling Kindle Package Manager (KPM) packages from KindleTweaks and KindleModding (KMC) into standard OPKG .ipk packages.

Quick Setup

Add the appropriate line to your /mnt/us/.eink-sdk/opkg/opkg.conf, then update and install:

opkg update
opkg install jobman
opkg install koreader
